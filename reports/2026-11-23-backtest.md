## Setup

- Data: synthetic, seed 7, hash `c01e9fc09d2f0689`, 2024-01-01 to 2026-10-31. Invented lanes; the shapes (weekday, peak season, holidays, promotions, one lane losing a customer) are the ones real freight shows.
- Origins: 2026-03-21, 2026-04-18, 2026-05-16, 2026-06-13, 2026-07-11, 2026-08-08, 2026-09-05, 2026-10-03.
- Forecast windows run 2026-03-22 to 2026-10-31, so the November and December peak is not in this backtest: peak-season accuracy is untested.
- Models: default settings chosen before the first backtest; nothing was tuned against these origins.
- Package version 0.1.0. Reproduce: `freight-forecast backtest --seed 7 --origins 8`.
